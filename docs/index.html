Overview

A line-by-line, source-verified study of fantasylabs.com/articles and the data-quality system behind its projections — plus an original open projection engine you can run yourself.

Verification promise Every factual claim on this site carries a source link back to the Source Ledger (50 sources, Class A = official/primary). Nothing was scraped behind the paywall; nothing subscription-only is reproduced — see Paywall & legal.

What FantasyLabs is

DFS analytics platform founded by Fabrizio, Bales, Jennings, Cassata & Bernhardt; Cuban-backed; rolled into The Chernin Group's Action Network (Oct 2017); later acquired by Better Collective for $240M (May 2021). S24 S28

The data-quality core

Salary-based expectations power an entire metric family — Plus/Minus, Consistency, Upside, Duds, Bargain Rating, Opponent +/-. All officially documented in public glossaries. Metric library →

The tool stack

Player Models (weighted factors + R² backtest), Trends database, Lineup Optimizer, SimLabs simulations, ownership, Vegas, PickLabs — all mapped with links. Feature map →

Our rebuild

engine/ reimplements the public definitions as tested original code: expectation model, 14 metrics, weighted model, trends runner, optimizer, Monte-Carlo simulator, official DK/FD scoring. 79 tests passing. Methodology →

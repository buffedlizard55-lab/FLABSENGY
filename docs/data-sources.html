Data sources

Lawful substitutes that get us to comparable data quality. Rated GREEN (clearly open/licensed), YELLOW (personal-use gray zone), RED (avoid / ToS-prohibited).

Hard rules for this repo ① Never fetch from fantasylabs.com programmatically (ToS S27). ② Never use undocumented DraftKings/FanDuel endpoints at scale (I16). ③ Never redistribute league data commercially without checking each license (I16).

Minimum viable pipeline

  1. NFL: pull nflverse weekly player stats + schedules (CC-BY, attribute).
  2. Salaries: export today’s DK/FD contest CSV from your account; store snapshots for the salary→expectation fit.
  3. Scoring: use scoring.py (official tables) to convert raw stats → DK/FD points.
  4. Fit ExpectationModel on (salary, points) history → Plus/Minus family.
  5. Weight your factors in WeightedPlayerModel; watch R² vs historical +/−.
  6. Research edges with run_trend(); ignore samples below the confidence threshold.
  7. Build lineups with stacks/groups/exposures; stress-test with SlateSimulator.

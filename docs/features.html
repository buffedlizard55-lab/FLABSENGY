Deep-dive: the six “Pro Tools”

Player Models core

User-weighted factor model producing live player ratings; backtested against historical Plus/Minus with an R² tile; factors publicly named include Vegas Score, Lineup Order Percentile, Park Factor “and much more”. S17

Lineup Optimizer

Inputs: projections (baseline from Sean Koerner for NFL), ceiling/floor, custom uploads, aggregates; salary constraints; correlation/stack rules; player groups & exposures; ownership. Up to 300 lineups. S16 S4

Trends

Historical database of salaries × performances with filterable “trends”. Outputs: Count, Avg Expected, Avg Actual, Points +/−, Consistency + charts by day/month. S14

SimLabs

Monte-Carlo pipeline: simulate games → lineup pool → shape to projected field → simulate contests → rate lineups 0–99 vs the “universe”; weight sliders for simulation/ownership/projection/correlation. S19

PickLabs

Player-props / pick’em edge tool with per-operator pages (10 operators listed in nav). S3

Contest Dashboard

Contest-level view paired with ownership projections — dashboard + ownership pages exist per sport in nav. S3
